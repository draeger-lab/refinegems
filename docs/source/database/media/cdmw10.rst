Chemically Defined Medium as described in Wegkamp et al. 2010 (CDMW10)
^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^

The CDMW10 medium is a chemically defined medium that is described by Wegkamp *et al.*:footcite:p:`Wegkamp2010`. 
The following *in silico* definition contains all components as described in 'Development of a minimal growth medium for 
*Lactobacillus plantarum*'\ :footcite:p:`Wegkamp2010` (Table 1).
