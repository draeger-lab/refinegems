Plantarum Minimal Medium for *L. plantarum* WCFS1 (PMM5, true minimal medium)
^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^

PMM5 is a true minimal medium for *Lactiplantibacillus (former: Lactobacillus) plantarum* WCFS1 first described by 
Wegkamp *et al.*:footcite:p:`Wegkamp2010`.  The following *in silico* definition contains all components as described in 
'Development of a minimal growth medium for *Lactobacillus plantarum*'\ :footcite:p:`Wegkamp2010` (Table 1).
