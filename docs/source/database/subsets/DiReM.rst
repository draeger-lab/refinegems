:icon:`fa-solid fa-bolt`:icon:`fa-solid fa-arrows-rotate` Dissipation reaction metabolites (DiReM)
^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^

This subset contains the metabolites needed for the dissipation reactions to check for energy-generating cycles (EGCs) 
in a model as described by Fritzemeier *et al.*:footcite:p:`fritzemeier2017erroneous`.

.. caution::

  This subset is not meant for growth analyses purposes as it holds no biological meaning when adding it to a medium.
