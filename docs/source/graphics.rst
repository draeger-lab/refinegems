Documentation Graphics Licence
==============================

The refineGEMs source code is licensed under the MIT licence. Project-created
documentation graphics are licensed separately under `Creative Commons
Attribution 4.0 International
<https://creativecommons.org/licenses/by/4.0/>`__ (CC BY 4.0).

The asset-side notice is stored in
``docs/source/images/GRAPHICS_LICENSE.md``. It covers project-created figures,
diagrams, plots, and documentation navigation graphics in
``docs/source/images/``, except for the logo files in
``docs/source/images/logos/``.

The logo files have their own notice in
``docs/source/images/logos/LOGO_LICENSE.md`` and their own :doc:`brand usage
guide <brand>`.

Future Graphics
---------------

This licence should only be applied to graphics created by the refineGEMs
project owners or contributors, or to graphics for which the project has clear
permission to apply CC BY 4.0.

Third-party graphics, externally sourced screenshots, publisher figures, vendor
material, or database images are not covered unless they are explicitly listed
in ``docs/source/images/GRAPHICS_LICENSE.md`` or accompanied by a compatible
notice.
